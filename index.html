About this site

Curiosity, in progress.

ScottCode.fun is a personal playground for learning, building, and sharing small digital projects.

What is ScottCode?

A simple web home for coding projects, browser games, and experiments. The goal is to keep the experience quick, friendly, and easy to use on phones as well as computers.

The site is designed as a single-page app, so its navigation switches between views without sending you through a maze of separate files.

Built with

  • HTML, CSS, and JavaScript
  • Responsive, touch-friendly layouts
  • Cloudflare Worker API integration for accounts
  • Formspree for the contact form
